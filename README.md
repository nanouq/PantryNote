# PantryNote

PantryNote is a modern full-stack web application designed to help users efficiently manage their kitchen inventory. The application was built as a capstone project, and was initially hosted using Azure. 

## Features
- Item Management: Users can add, edit, and delete items.
- User Authentication: Secure sign-up and login functionality.
- Search Functionality: Search through items added to your pantry.

## Stack
### Backend
- C# ASP.NET Core MVC
- SQL Server
- Entity Framework Core

### Frontend
- HTML/CSS/JS
- Bootstrap

## Features to add
- Recipe integration: Create recipes based off of items added to your pantry using an API.
- AI Suggestions/Insights: Determine projected expiration dates based on usage trends.
- Email Alerts: Send users emails (when opted-in) when their items are going to expire.
- Mobile Application
